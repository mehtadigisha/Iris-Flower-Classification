 # 🌸 Iris Flower Classification - Machine Learning Project

This project implements a **Supervised Machine Learning** model using **Support Vector Machine (SVM)** to classify iris flowers into three species: *Setosa*, *Versicolor*, and *Virginica*. The model is trained on the classic **Iris dataset**, and includes data visualization, model training, prediction, and evaluation.

---

## 🚀 Features

- 📊 Exploratory Data Analysis with **Seaborn** and **Matplotlib**
- 🤖 SVM (Support Vector Classification) for model building
- 🧪 Model evaluation using **Accuracy Score** and **Classification Report**
- 🔮 Predict the species of Iris flower based on input features
- ✅ Beginner-friendly and well-commented code

---

## 📚 Dataset

The **Iris dataset** contains 150 samples of iris flowers, with the following features:

- `Sepal Length`
- `Sepal Width`
- `Petal Length`
- `Petal Width`

Target classes:
- `Iris-setosa`
- `Iris-versicolor`
- `Iris-virginica`
